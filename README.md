### Updateコマンドについて

パッケージのメジャーバージョン（破壊的変更を含む大幅な更新）へ安全にアップデートするには、主に以下の2つの方法があります。
------------------------------
## 方法1：npm-check-updates (ncu) を使う（最もおすすめ）
npm 標準の機能ではメジャーバージョンの一括更新が難しいため、開発者の間で最も広く使われている外部ツールです。

   1. ツールの実行（インストール不要）
   package.json があるディレクトリで以下を実行します。
   
   npx npm-check-updates -u
   
   * ※ npx を使うことで、ツールをPCにインストールせずにその場で実行できます。
      * ※ -u（--upgrade）オプションにより、package.json の中のバージョン記述がすべて最新のメジャーバージョンに書き換わります。
   2. パッケージのインストール
   package.json が書き換わったら、実際にパッケージをダウンロードして同期します。
   
   npm install
   
   
------------------------------
## 方法2：npm install で個別指定する
特定のパッケージだけをピンポイントでメジャーアップデートしたい場合は、npm install コマンドで @latest タグを指定するのが一番シンプルです。

npm install <パッケージ名>@latest


* 例: npm install axios@latest
* これにより、指定したパッケージが既存のバージョン制限（^ や ~）を無視して、強制的に最新のメジャーバージョンに更新され、package.json も上書きされます。

------------------------------
## メジャーアップデート時の注意点 ⚠️

* コードが壊れる可能性があります: メジャーアップデートでは、関数の名前が変わったり廃止されたりする「破壊的変更」が含まれます。アップデート後は必ずテストを実行し、動作確認を行ってください。
* Gitでコミットしておく: 万が一動かなくなった場合にすぐ元の状態に戻せるよう、コマンドを実行する前に現在のコードをコミット（保存）しておくことを強く推奨します。

どちらの方法で進めたいですか？状況に合わせてサポートします。

   1. npx npm-check-updates を使ってプロジェクト全体を一括更新したい（手順に不安があれば補足します）
   2. 特定のパッケージだけを個別にメジャーアップデートしたい（具体的なコマンドを作成します）
   3. アップデート後にエラーが出ないか心配なので、注意すべきポイントを知りたい
